# Contributing to Crypto Wallet

Thank you for contributing to Crypto Wallet.

## Contribution Workflow

1. Fork this repository.
2. Clone your fork.
3. Create a new branch.
4. Make your changes.
5. Run the tests and build locally.
6. Commit your changes.
7. Push the branch to your fork.
8. Open a Pull Request against `main`.
9. Wait for review.
10. Address any requested changes.
11. Once approved, the Pull Request may be merged.

## Branch Naming

Use descriptive branch names.

Examples:

- feature/biometric-auth
- feature/wallet-import
- fix/transaction-history
- security/private-key-storage
- docs/update-readme

## Security

Never commit:

- Private keys
- Seed phrases
- Passwords
- API keys
- Authentication tokens
- Wallet credentials
- Personal information

If you discover a security vulnerability, do not publicly disclose it in an issue. Follow the project's security reporting process.

## Pull Requests

Every Pull Request should:

- Explain what changed.
- Explain why the change is needed.
- Include relevant tests.
- Keep changes focused.
- Avoid unrelated modifications.
